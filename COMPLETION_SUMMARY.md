## 📋 Next Steps to Go Live

### STEP 1: Configure Stripe Live Keys (15 mins)
1. Create Stripe account: https://stripe.com/
2. Verify business (South Africa, Rand currency)
3. Get **live publishable key** (pk_live_...)
4. Get **live secret key** (sk_live_...)
5. Update in `index.html` line ~915
6. Update in `create-checkout-session.php` line 6

### STEP 2: Register Domain (1 day)
1. Go to registrar (e.g., Afrihost.com for South Africa)
2. Register: `lavishbites.co.za`
3. Get nameserver info
4. Point to your hosting provider

### STEP 3: Install SSL Certificate (30 mins)
1. Log into hosting control panel
2. Find SSL/TLS section
3. Install Let's Encrypt (free) or purchase certificate
4. Verify HTTPS works (green lock icon)
5. Force HTTPS redirect

### STEP 4: Upload Files (30 mins)
1. Download all files
2. Connect via FTP or Git
3. Upload to `public_html/` directory
4. Ensure `.env` file is NOT public (keep secret keys safe)

### STEP 5: Test Payment (30 mins)
1. Test with real card (won't be charged yet)
2. Verify success page loads
3. Check Stripe dashboard for transaction
4. Test on mobile device

### STEP 6: Configure Email (30 mins - Optional)
1. Set up email for order confirmations
2. Configure SMTP if needed
3. Test email sending

### STEP 7: Launch! 🎉
1. Verify all compliance pages accessible
2. Double-check all links work
3. Test on multiple devices
4. Announce to customers
